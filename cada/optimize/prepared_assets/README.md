# Prepared optimization assets

This directory is generated by `scripts/register_prepared_solutions.py` from
the curated champions in `offline_results/`.  Runtime lookup does not use case
names: `manifest.json` records objective/constraint contracts plus structural
and sampled-behaviour fingerprints, and artifacts are loaded lazily by SHA-256.
Fingerprint v2 also binds each DFF instance to its Q net for safe exact reuse.

Every hit is only a candidate.  `cada.optimize.resynth` recomputes its true
cost and checks the requested basis/fanout contract.  An exact-current match
reuses the artifact's offline CEC and runs 4,096 sanity patterns; a structurally
different semantic match must pass 100,000 total directed and deterministic-
random register-cut patterns.  Any mismatch, timeout, corruption, or incompatible
contract falls back to the ordinary online portfolio.  All later online
resynthesis candidates still require whole-design CEC.

`cone_depth` objectives are intentionally not stored here.  They always use
the generic runtime cone extraction/optimization/splice flow and finish with a
fresh whole-design CEC; this bank contains only whole-design objectives.

Regenerate and verify the current bank with:

```sh
python3 scripts/register_prepared_solutions.py --verify-cec
python3 scripts/verify_prepared_registry.py --full
python3 scripts/verify_prepared_runtime.py
```

Do not hand-edit files under `artifacts/`.  The test35 entry explicitly records
the legacy evaluator contract that permits its scoped net to be eliminated;
missing basis scopes are rejected for every unmarked candidate.
